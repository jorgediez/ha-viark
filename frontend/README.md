# Viark remote card: source

The source of the dashboard card that ships with the Viark integration. Home
Assistant serves the build, which is committed to
`custom_components/viark/www/viark-remote-card.js`.

- Using the card: [README → Remote card](../README.md#remote-card)
- Building and testing it: [README → The remote card](../README.md#the-remote-card)
  and [CONTRIBUTING.md](../CONTRIBUTING.md#working-on-the-code)

Until version 1.4.0 the card was its own project,
[ha-viark-remote-card](https://github.com/jorgediez/ha-viark-remote-card). Its
history is part of this repository's.
